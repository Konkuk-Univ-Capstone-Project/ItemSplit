# S3 저장·조회·삭제 요구사항 및 API 확장 범위

영수증 이미지를 S3에 저장·조회·삭제하기 위한 요구사항과, 이를 위해 변경하거나 추가할 API 범위를 정리한다. 기준 코드는 `main` 4671a0c (PR #16 머지 후)이다.

## 1. 현재 상태

| 항목 | 현재 | 문제 |
|---|---|---|
| 업로드 | `POST /api/rooms/{roomId}/receipts/image` → 로컬 디스크 저장 후 `IMAGE_UPLOAD` 영수증 생성 | 화면에서 호출하는 곳 없음 |
| 조회 | API 없음 | 올린 이미지를 볼 수 없음 |
| 삭제 | 영수증·방 삭제 시 커밋 후 파일 삭제 (PR #16) | 재시도 큐가 로컬 디스크 `.cleanup-pending` |
| 검증 | `Content-Type` 헤더가 `image/*`인지만 확인 | 헤더는 위조 가능, 크기 제한 없음 |
| 크기 | nginx 기본 1MB, Spring 기본 1MB | 휴대폰 사진(3~10MB) 대부분 업로드 실패 |
| 응답 | `storedPath`(내부 저장 경로) 노출 | 내부 키가 클라이언트에 노출 |
| 구현체 선택 | `LocalStorageService`가 무조건 빈 등록 | S3로 전환할 설정 없음 |

## 2. 기능 요구사항

### 저장
- **S-1** 이미지 원본은 비공개 S3 버킷에 저장한다. 버킷·객체의 공개 접근은 차단한다.
- **S-2** 객체 키는 `receipts/{roomId}/{UUID}.{ext}` 형식으로 서버가 만든다. 원본 파일명은 키에 쓰지 않고 DB 메타데이터로만 보관한다.
- **S-3** DB에는 객체 키·원본 파일명·형식·크기만 저장한다. 만료되는 조회 URL은 저장하지 않는다. (계약 문서 §4)
- **S-4** 허용 형식은 JPEG, PNG, WEBP다. 헤더가 아니라 **파일 앞부분 바이트(매직 넘버)** 로 실제 형식을 확인한다.
- **S-5** 최대 크기는 10MB다. nginx·Spring·화면 세 곳의 제한을 같은 값으로 맞춘다.
- **S-6** 영수증 하나에 이미지는 1장이다.
- **S-7** 업로드 후 DB 저장이 실패하면 올린 객체를 지운다. (기존 `deleteAfterRollback` 재사용)

### 조회
- **R-1** 해당 방 멤버만 원본 이미지를 볼 수 있다. 공유 토큰으로는 볼 수 없다. (계약 문서 §4)
- **R-2** 화면은 `<img src>`로 이미지를 띄우는데, `<img>`는 `Authorization` 헤더를 보내지 못한다. 그래서 **권한을 확인한 뒤 짧은 시간만 유효한 URL**을 내려준다. S3는 presigned GET URL을 쓰고 유효 시간은 5분이다.
- **R-3** 로컬 저장소도 같은 API 계약을 지킨다. 화면이 저장소 종류를 몰라도 되게 한다.

### 삭제
- **D-1** 영수증·방 삭제 시 DB 커밋 후 객체를 삭제한다. (기존 `deleteAfterCommit` 재사용)
- **D-2** 삭제 실패는 재시도한다. 재시도 기록은 컨테이너를 다시 만들어도 사라지지 않아야 한다.
- **D-3** 커밋 직후 프로세스가 죽어 놓친 객체는 주기적 대조(DB에 없는 키 삭제)로 정리한다.

### 운영
- **O-1** `app.storage.type=local|s3` 설정으로 구현체를 고른다. 기본값은 `local`이어서 AWS 없이도 로컬 개발·테스트가 된다.
- **O-2** S3 설정은 환경변수(`S3_BUCKET`, `AWS_REGION`)로 받는다. 자격 증명은 코드·설정 파일에 두지 않는다.
- **O-3** S3 구현체 테스트는 LocalStack(Testcontainers)으로 실제 AWS 없이 돌린다.

## 3. API 확장 범위

| 구분 | API | 변경 내용 |
|---|---|---|
| 변경 | `POST /api/rooms/{roomId}/receipts/image` | 형식(매직 넘버)·크기 검증 추가, 응답에서 `storedPath` 제거 |
| 신규 | `GET /api/rooms/{roomId}/receipts/{receiptId}/image` | 방 멤버 확인 후 `{ url, expiresAt, contentType }` 반환. 이미지 없으면 404 |
| 변경 | `GET .../receipts`, `GET .../receipts/{receiptId}` | `hasImage` 필드 추가 |
| 유지 | `DELETE .../receipts/{receiptId}`, `DELETE /api/rooms/{roomId}` | 파일 정리는 PR #16에서 구현됨. 구현체만 S3로 교체 |
| 범위 밖 | 이미지 교체·추가, OCR 상태·초안 | 이 문서에서 다루지 않음 |

## 4. 비기능 요구사항

- 업로드 응답 시간: 10MB 기준 서버 처리 3초 이내
- 조회 URL 발급: DB 조회 1회 + 서명 계산 (S3 호출 없음)
- 로그에 presigned URL 전체를 남기지 않는다 (서명 포함)

## 5. 정해야 할 것

아래 값은 현재 결정값으로 진행하고, 팀 논의 결과가 다르면 수정한다.

| 항목 | 현재 결정 | 바뀔 수 있는 경우 |
|---|---|---|
| 이미지 형식 | JPEG, PNG, WEBP | 아이폰 HEIC를 받아야 할 때 (화면에서 JPEG로 변환해 올리는 방법 권장 — 브라우저 대부분이 HEIC를 표시하지 못함) |
| 최대 크기 | 10MB | 화면에서 올리기 전에 리사이즈할 때 |
| 영수증당 이미지 | 1장 | 긴 영수증을 나눠 찍는 경우까지 지원할 때 |
